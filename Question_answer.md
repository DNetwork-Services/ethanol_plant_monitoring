Q1. Why did you use Node.js?

"I had prior experience with Node.js, so I used it to build a lightweight REST-based application and focused my learning on the cloud and DevOps implementation around it."

Q2. Why Express?

"Express provides a lightweight framework for building HTTP APIs and web applications on Node.js."

Q3. What is port 5000?

"It's the port on which our Node application listens for incoming HTTP requests in our local environment."

Q4. Why use process.env.PORT?

"It allows the application port to be configured through an environment variable, which is useful when deploying the same application across different environments, especially containers and cloud platforms."
