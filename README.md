# Ethanol Plant Monitoring Platform

A cloud-native DevOps project representing a simplified monitoring platform for an industrial ethanol plant.

## Technology Stack

- Node.js
- Express
- Docker
- Git
- GitHub
- AWS
- Terraform
- GitHub Actions
- Amazon ECR
- Amazon EC2
- CloudWatch

## Application

The application currently provides:

- Plant monitoring dashboard
- Health check endpoint
- Plant data REST API

## DevOps Roadmap

1. Develop Node.js application
2. Containerize with Docker
3. Version control with Git
4. Push source code to GitHub
5. Build CI/CD pipeline
6. Provision AWS infrastructure using Terraform
7. Push Docker image to Amazon ECR
8. Deploy application to AWS
9. Configure monitoring and logging
10. Implement production-style security and deployment practices
